# 🟢 طرح معماری سیستم دستیار کارشناسی فرش

**نسخه:** 1.0 — امروز: 1405/08/26 (2026-11-18)  
**کاربر:** کارشناس رسمی دادگستری (رشته فرش)

---

## 1. چشم‌انداز و قوانین طلایی (بسیار مهم)

### 1.1. اصل اساسی
این سامانه یک **دستیار هوشمند** است، نه جایگزین نظر قضایی. هر خروجی (تشخیص تصویر + قیمت) باید با **امضای دیجیتال** کارشناس تأیید شود.

### 1.2. مدیریت ریسک
- هیچ مدل هوش مصنوعی به تنهایی قاضی نیست
- تصمیم نهایی همیشه با انسان است
- هر تخمین باید دارای **محدوده اطمینان** (Confidence Interval) باشد
- تمام ورودی‌ها باید ذخیره و قابل پیگیری باشند (Audit Trail)

### 1.3. محدودیت‌های واقعی
| محدودیت | توضیح |
|----------|-------|
| منابع کاملاً رایگان | Google Workspace (Sheets, Drive, Apps Script, Gemini via AI Studio) |
| حجم آپلود تصویر | حداکثر 20MB در Gemini (اندروید) |
| تعداد درخواست AI | ~۱۰۰۰ درخواست/day در پلان Free (Gemini) |
| جمع‌آوری قیمت آنلاین | دیوار/شیپور/API عمومی ندارند — بخش عمده نیاز به ورود دستی/CSV دارند |
| فرآوری تصویر | مدل Vision باید آموزش‌دیده یا فرهنگ‌سازی شود |

## 3. فاز ۱: جمع‌آوری و ساخت داده‌های پایه

### 3.1. هدف
ساختن **پایگاه دانش فرش** اولیه برای آموزش/تست مدل.

### 3.2. ساختار داده‌های ضروری

#### 📋 جدول اصلی فرش (carpet_inventory)
| فیلد | نوع | توضیح |
|------|-----|--------|
| carpet_id | auto | شناسه یکتا |
| name | text | نام فرش/لقب |
| category | text | قالین، گلیم، جانمایی، خورجین، تد |
| region_weave | text | منطقه بافت (تبریز، قاشقائی، گرگان، بندباف، اصفهان...) |
| pattern_type | text | نام نقشه (شفای، لچک، افشان، معین، دستمایا، گنبد...) |
| weave_density | number | رگشمار (عدد مسطح) |
| size_width | number | عرض (سانتی‌متر) |
| size_length | number | طول (سانتی‌متر) |
| material | text | پشم، ابریشم، کتان، موسکین، ترکیبی |
| dye_type | text | رنگ طبیعی (گیاهی) / رنگ مصنوعی |
| age_year | number | قدمت (تقریبی) |
| condition | text | نو، قدیمی، ترمیم‌شده |
| image_path | text | آدرس تصویر در Drive |
| notes | text | یادداشت کارشناس |
| created_at | datetime | زمان ثبت |

#### 📋 جدول قیمت (price_database)
| فیلد | نوع | توضیح |
|------|-----|--------|
| price_id | auto | شناسه یکتا |
| carpet_id | text | ID مرتبط |
| price | number | قیمت (تومان) |
| date | date | تاریخ قیمت |
| source | text | منبع قیمت (دستی، دیوار، شیپور، مرجع) |

## 4. فاز ۲: موتور تشخیص تصویر (Computer Vision)

### 4.1. گزینه‌های AI رایگان

#### ✅ گزینه پیشنهادی: Gemini 2.5 Pro (via Google AI Studio)
- **نقش سیستمی (System Prompt):** "شما یک کارشناس ۲۰ ساله فرش هستید. وظیفه شما تشخیص منطقه بافت، حماسه نقشه، نوع متریال و تخمین عمر است"
- **ورودی:** تصویر (应交 ≤ 20MB)
- **خروجی Expected JSON:** ساختار داده از ساختار ذخیره‌سازی

```json
{
  "region_weave": "",
  "pattern_type": "",
  "weave_density": "",
  "material": "",
  "dye_type": "",
  "age_year": "",
  "catalogue": "",
  "confidence": ""
}
```

#### ✅ گزینه جایگزین: Google Cloud AutoVision (رایگان محدود) / SageMaker
- خواب‌اندازی: پیچیده‌تر

### 4.2. فرم Prompt Exact (Pattern-Matching)
_اینجا نمونه تخمینی است_

```
System: You are a carpet expert with 20+ years of experience.
Task: Analyze this carpet photo and provide structured output.

Prompt: 
"این یک تصویر فرش است. لطفاً موارد زیر را تشخیص دهید:
1. منطقه بافت (از لیست: تبریز، قاشقائی، بن‌باف، گرگان، گنبد، اصفهان، قم، سمنان، کاشان، کرمان و شیک، تبریز قدیمی، لاهیجان، میانه، ...
2. نوع نقشه (لچک، افشان، دستمایا، شکار، گلاداری، طرح بسیار، ختایی، ...)
3. تراکم پشم (دسته‌بندی: ۳۰-۴۰ دسته، ۴۰-۵۰ دسته، ۵۰-۶۰ دسته، ۶۰+)  
4. نوع الیاف (پشم، ابریشم، کتان)
5. وضعیت رنگ (رنگ گیاهی/طبیعی یا مصنوعی)
6. تخمین عمر (۰-۵ سال، ۵-۱۰ سال، ۱۰-۲۵ سال، ۲۵-۵۰ سال، ۵۰+ سال)

لطفاً به صورت JSON خروجی دهید."
```

### 4.3. عمل Crown: Validation
- اگر مقدار پتانسیل پایین بود (مبارزه < ۵۰٪) — عملیات **ابتلا مجدد** بستاند
- اگر اشکال سیستمی بود — هشدار بده

## 5. فاز ۳: موتور قیمت‌گذاری (Pricing Engine)

### 5.1. فرمول پایه
```
قیمت پایه (متر مربع) × بالاترین قیمت منطقه + (نقشه خاص × ۰.۲) + (تراکم بالا × ۰.۱۵) + (سن بالای ۲۰ × ۰.۴) + (شرایط خاص)
```
_توجه:_ این فرمول یک مثال است — باید با داده واقعی کالیبره شود.

### 5.2. فاکتورهای تأثیرگذار
| فاکتور | تأثیر | نمونه |
|--------|--------|--------|
| منطقه بافت | ±۳۰-۴۰٪ | تبریز ≥ قاشقائی ≥ سایر |
| تراکم | ±۱۰-۱۵٪ | بالا = بهای بیشتر |
| نوع الیاف | ±۵-۴۰٪ | ابریشم = فرش عالی |
| رنگ | ±۵-۱۰٪ | گیاهی = باارزش‌تر |
| سن | ±۱۰-۸۰٪ | پراکنده‌ترین_estimate |
| اندازه | ±۵-۱۰٪ | بزرگتر = بیشتر |
| کیفیت | ±۱۰-۵۰٪ | تمیز بودن |

### 5.3. منبع قیمت
- **پیشنهاد:** ورودی دستی به همراه Publish CSV هفته‌ای از دیوار/شیپور
- **NOT:** Scraping خودکار (Risk of IP blocked & Terms violation)

### 5.4. تخمین قیمت = میانگین + محدوده
```
قیمت تخمینی = میانگین وزن‌دار منبع + سامانه کمکی
حداقل → حداکثر قیمت = قیمتی که ممکن است باشد
```

## 7. فاز ۵: اعتبارسنجی و خروجی (Judicial)

### 7.1. خروجی گزارش (Report)
- فرمت PDF (ثبت شده در Google Drive)
- شامل: اطلاعات فرش، عکس، تشخیص AI، قیمت تخمینی، محدوده اعتماد، امضای دیجیتال

### 7.2. Audit Trail
- **هر** درخواست AI با timestamp و ID مشتری ذخیره می‌شود
- **هر** قیمت با source و timestamp ذخیره می‌شود

### 7.3. Wrap-up
- فرم تأیید نظر کارشناس (Sign-off)
- امکان `approve`/`override`
